godot-correctness-mcp

Offline static correctness MCP server (and gdcorrect CLI) for Godot 4.x GDScript projects. It runs headless, offline, and in CI: no editor, no running Godot instance, no network at runtime.

Pillars

  • GDScript linting with a committed tree-sitter grammar: lint rules and config
  • Cross-version API lookup and diff for Godot 4.4 and 4.5: symbol databases
  • Scene, project, and registry analysis for .tscn, .tres, and project.godot: checks

Use it as an MCP server

{
  "mcpServers": {
    "godot-correctness": {
      "command": "npx",
      "args": ["-y", "@tmhs/godot-correctness-mcp"]
    }
  }
}

Use it in CI

npx -y -p @tmhs/godot-correctness-mcp@^0.2 gdcorrect lint . --format json

Exit code 0 is clean, 1 means error-severity findings, and 2 means a tool failure.

Tools

server_info, api_symbol_lookup, api_class_summary, api_diff, lint_file, lint_project, list_rules, validate_scenes, validate_project_config, validate_registries, project_report.
